# 网站使用手册

适用对象：

- 客户 / 学生 / 家长
- 管理员 / 运营 / 顾问老师

当前本地预览地址：

- 前台首页：`http://127.0.0.1:4322/`
- 管理员后台：`http://127.0.0.1:4322/admin`

---

## 1. 网站整体结构

网站目前分为两大部分：

1. 前台网站
2. 管理员后台

前台用于客户查看服务、师资、考试、出分案例、留学申请信息，并提交咨询。

后台用于管理员维护站点内容、查看咨询线索、运行留学底库同步、维护选校数据质量。

---

## 2. 客户使用手册

### 2.1 首页怎么用

打开首页后，客户可以完成以下操作：

1. 查看品牌介绍和核心服务
2. 进入语言培训、留学申请、考试、师资等模块
3. 查看最新动态
4. 通过右下角咨询浮窗或页面底部表单发起咨询

首页主要入口：

- `首页 /`
- `选校 /school-finder`
- `服务 /services`
- `考试 /exams`
- `师资 /teachers`
- `动态 /#news`
- `联系 /#contact`

---

### 2.2 右下角在线咨询怎么用

网站右下角会弹出在线咨询窗口。

客户可以：

1. 直接输入咨询问题
2. 点击国家 / 阶段等快捷选项
3. 留下电话、微信或邮箱
4. 跳转到预约咨询区域

咨询窗口的作用：

- 快速收集客户意向
- 引导客户进入留学申请咨询
- 将用户消息发送到管理员邮箱

建议客户填写的信息：

- 意向国家
- 申请阶段
- 当前年级
- 联系方式
- 主要问题

---

### 2.3 选校功能怎么用

选校页地址：

- `/school-finder`

这是网站里最重要的工具页之一，适合学生和家长做第一轮选校筛选。

#### 第一步：基础筛选

可选字段：

- 意向国家
- 学位类型：本科 / 硕士 / 博士
- 专业方向
- 细分方向

系统会先根据这些条件缩小学校池和项目池。

#### 第二步：申请背景

可选字段：

- 预算上限
- 入学季
- 当前 GPA
- 语言成绩
- 背景策略
- 门槛质量

说明：

- 预算和入学季会用于硬筛选
- GPA 和语言成绩会优先用于排序和匹配提示
- 门槛质量可控制只看已同步或结构化程度更高的项目

#### 第三步：点击“开始搜索”

点击后会得到三层结果：

1. 学校池
2. 项目结果
3. 候选官网页（如有）

#### 学校池怎么理解

学校池用于先缩学校范围。

客户可以继续按：

- 学校关键词
- 城市关键词
- QS 排名
- 是否有学费
- 是否有项目

进一步缩小范围。

#### 项目结果怎么看

每个项目卡一般会展示：

- 学校名称
- 中文校名（如已补齐）
- 国家 / 城市
- 项目名称
- 学位
- 学费（若已入库）
- QS 排名（若已入库）
- 官方项目页
- 招生要求摘要

#### “查看要求摘要”是做什么的

点击后，系统会尝试展示：

- GPA 要求
- IELTS / TOEFL / PTE
- GRE / GMAT
- 工作经验
- 官网要求说明

这部分是为了帮助客户判断项目要求是否匹配。

#### 候选官网页是什么

如果系统没有足够多的已核验项目结果，会补充展示候选官网页。

这类结果的作用：

- 扩展选校线索
- 补充未来可能入库的官方项目页

它们不等同于正式已核验项目。

- 适合人群

### 2.5 考试页怎么用

考试页地址：

- `/exams`

- TOEFL
- IELTS
- GRE

- TOEIC

点击后可进入考试详情页，查看考试说明、备考重点和相关服务。

### 2.6 师资页怎么用

师资页地址：

- `/teachers`

客户可查看：

- 老师姓名
- 职位 / 头衔
- 擅长方向
- 简介

点击老师可进入个人详情页，进一步查看授课特色和背景。

---

### 2.7 最新动态怎么用

首页和前台会展示“最新动态”。

用途：

- 展示考试、留学、申请相关动态
- 让客户看到网站有持续更新

说明：

- 动态内容来自配置好的新闻抓取 / 内容源
- 不是管理员手动逐条发文章的博客系统

---

### 2.8 底部联系表单怎么用

页面底部有预约咨询 / 预约试听入口。

客户需要填写：

- 姓名
- 联系方式
- 预约类型
- 考试 / 服务类型
- 期望时间
- 具体需求

提交后：

1. 线索会进入后台
2. 系统会尝试发送邮件通知管理员

## 3. 管理员使用手册

后台地址：

- `/admin`

- `/admin/login`

注意：

- 后台账号密码来自环境变量

## 4. 留学底库页重点说明

### 4.1 统一底库同步

作用：

- 同步全球学校底库
- 同步英国项目种子
- 在具备正式条件时同步美国项目源
- 统一记录最近一次同步结果

你会看到：

- 最近一次同步时间
- 来源
- 净增学校 / 项目 / 国家
- 哪些源成功
- 哪些源失败
- 是否安全跳过美国源

如果没有正式 `COLLEGE_SCORECARD_API_KEY`：

- 系统会自动跳过美国源
- 不会因为 demo key 把同步撞进限流

---

### 4.2 招生门槛快照同步

作用：

把项目官网中的招生要求沉淀成结构化字段，例如：

- GPA
- IELTS
- TOEFL
- PTE
- GRE
- GMAT
- 工作经验

这一步对选校质量非常重要，因为：

- 客户前台能看到更清楚的要求摘要
- 系统能更好地做背景匹配和排序

---

### 4.3 热门方向预热

作用：

优先补齐最常被搜索的国家 + 方向组合。

例如：

- 美国 · 金融 · 硕士
- 美国 · 计算机 / AI · 硕士
- 英国 · 商科 / 管理 · 硕士

适合场景：

- 想先提高客户最常搜到的热门结果质量

---

### 4.4 智能预热

系统会自动评估：

- 哪些方向项目多
- 哪些方向门槛薄
- 哪些方向最值得先补

然后生成推荐列表。

适合场景：

- 不想人工判断下一步先补哪里
- 想优先提升实际产出

---

### 4.5 国家目标

系统会按国家跟踪目标覆盖率，例如：

- 美国
- 英国
- 中国香港
- 新加坡
- 加拿大
- 澳大利亚

你可以看到：

- 当前覆盖率
- 目标覆盖率
- 还差多少
- 推荐先补哪些方向

适合场景：

- 想平衡不同国家的数据厚度
- 不希望美国一直压住其它国家

---

### 4.6 覆盖冲刺 / 多轮推进

系统支持：

- 单轮冲刺
- 多轮路线图
- 推荐节奏执行

用途：

- 一次性连续推进多轮门槛补齐
- 让系统自己按节奏和优先级推进

---

## 5. 自动运行与脚本

项目已经支持统一命令入口。

常见命令：

### 5.1 底库同步

```bash
npm run study-abroad:catalog-sync
```

作用：

- 同步底库
- 记录最近同步状态
- 安全跳过当前不适合跑的源

### 5.2 留学门槛补齐

```bash
npm run study-abroad:campaign -- --mode=cadence
```

作用：

- 按系统推荐节奏补齐招生门槛
- 自动选择重点国家和方向

## 6. 客户常见问题

### Q1：为什么有些项目显示门槛已入库，有些没有？

因为招生门槛是逐步从官网同步并结构化的。

说明：

- 已入库：字段较完整
- 部分字段：已抓到一部分
- 待补抓：后续会继续补

### Q2：为什么有些结果是候选官网页？

因为系统在已核验项目不足时，会展示额外官网候选页作为扩展线索。

这类结果：

- 适合继续核对
- 不等于正式已核验项目

### Q3：为什么选校结果会变化？

因为：

- 底库在持续同步
- 招生门槛在持续补齐
- 推荐排序会根据背景和数据质量动态变化

## 7. 管理员常见问题

### Q1：为什么点击同步后，美国源有时没有执行？

因为当前如果没有正式 `COLLEGE_SCORECARD_API_KEY`，系统会自动安全跳过美国源，避免限流。

### Q2：哪些内容是手动维护的？

主要是：

- 老师
- 服务
- 考试
- 出分案例
- 站点基础信息
- 咨询浮窗文案

### Q3：哪些内容是自动补齐的？

主要是：

- 留学底库同步
- 候选官网页补抓
- 招生门槛快照同步
- 智能预热 / 国家目标 / 自动补齐

### Q4：后台打不开怎么办？

先确认：

1. 是否已启动站点服务
2. 是否访问了正确地址 `/admin`
3. 是否登录 session 失效

如果是本地预览，当前地址是：

- `http://127.0.0.1:4322/admin`

## 8. 建议的日常运营流程

### 每天建议

1. 查看后台首页
2. 看最近咨询线索
3. 看最近底库同步是否成功
4. 看最近门槛补齐是否有新增

### 每周建议

1. 检查热门方向搜索结果
2. 跑一轮底库同步
3. 跑一轮推荐节奏补齐
4. 查看国家目标和覆盖缺口

### 每月建议

1. 清理无效线索
2. 更新服务和案例内容
3. 检查重点国家项目层是否需要补厚
4. 复盘哪些方向客户搜索最多

## 9. 当前最推荐的使用方式

对客户：

- 先从首页进入
- 直接使用选校页
- 再进入咨询或预约表单

对管理员：

- 先看后台首页总览
- 再进留学底库页处理同步、预热和覆盖补齐
- 最后回到咨询线索做跟进
